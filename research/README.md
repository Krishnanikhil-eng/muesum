# MUESUM — Research Reference Literature

The following key computer vision and deep learning artwork inpainting papers inform the MUESUM architecture and restoration techniques:

1. **Image Inpainting: Overview and Recent Advances** (Survey of deep learning inpainting paradigms).
2. **Context-Aware Semantic Inpainting** (Convolutional skip connections and patch synthesis).
3. **High-Resolution Surface Defect Inpainting** (`applsci-15-01422`, Applied Sciences).
4. **Perceptual and Edge-Aware Loss Formulations** (`s11263-023-01977-6`, International Journal of Computer Vision).
5. **Historical Artwork Restoration with Deep Neural Networks** (`41598_2026_Article_35056`, Scientific Reports).

*Note: Large binary PDF files are excluded from git tracking to maintain a lightweight repository.*
